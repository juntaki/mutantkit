## Highlights

- A run in which no mutant was executed (a failing baseline, a baseline
  mismatch) no longer reports "every mutant that ran was killed" or "No
  mutants survived". The console, HTML and CI-summary reports now say "No
  mutants were executed." Runs that executed mutants print what they did
  before.
- The `Local packages:` line is printed only once the sandbox layout has been
  accepted, so a refused local package (for example an absolute path) is no
  longer described as "copied into each sandbox".

## Upgrade impact

None. No cache, checkpoint, plan or report format changed, so v1.1.0 results
remain reusable.

## Breaking changes

None.
