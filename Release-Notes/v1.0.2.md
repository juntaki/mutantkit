## Highlights

- Shortened `action.yml`'s top-level `description` to fit GitHub
  Marketplace's 125-character limit, and added a `branding` block
  (`icon: git-branch`, `color: purple`) so the Marketplace listing shows
  an icon instead of an error — clears the way to publish this Action on
  the GitHub Marketplace.
- `release.yml`'s `require-validation` job now auto-dispatches
  `release-validation.yml` and waits for it when no successful run exists
  yet for the tagged commit, instead of just failing closed. A tag can no
  longer fail to publish only because the ~80min real-simulator validation
  suite was not manually dispatched beforehand — the gate itself is
  unchanged: a tag still cannot publish without a genuine, successful
  validation run for its own commit.
- Brought every documented version pin (README, `action.yml`, `docs/ci.md`)
  in line with this release.

## Upgrade impact

None. `mode: install` and `mode: ci` behavior is unchanged; this release
only touches `action.yml`'s Marketplace metadata, the release pipeline's
own validation-gate sequencing, and documentation version pins.

## Breaking changes

None.
