## Highlights

- Four more mutation operators promoted from isolated-only to schemata
  scoring, each gated on a real-corpus isolated-vs-schemata differential
  run showing zero disagreement: logical-connector-replacement,
  unary-not-removal, return-value-replacement, ternary-branch-swap.
- New `mutantkit gate --baseline` quality gate: fail CI on a real
  mutation-score regression against a stored baseline, not just an
  absolute threshold.
- Inline `mutantkit:disable` comments for fine-grained, per-line mutation
  suppression.
- README now leads with `brew install`, with corrected schemata status
  and boundary guidance.

## Upgrade impact

No configuration or CLI-flag changes. Existing plans, reports, and
configs from `v0.1.0-alpha.1` remain valid; the newly-promoted operators
apply automatically only where schemata execution is already selected.

## Breaking changes

None.
