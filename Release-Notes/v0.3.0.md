## Highlights

- First-party GitHub Action (`uses: juntaki/mutantkit@v0.3.0`), rebuilt
  from scratch against current `main`, plus machine-readable CLI output
  and a golden-path onboarding pass for new users.
- Real CI test-selection soundness fixes: closed cases where a
  zero-match filter or unwired wave-acceptance config silently skipped
  tests instead of failing, and fixed silent output truncation that
  could masquerade as complete subprocess capture.
- Per-test coverage correctness: ported LLVM's real coverage-segment
  semantics (complete-or-nil evidence, no partial maps), fixed
  `SourceCoverageReader` dropping a region's own same-line closing line,
  and fixed `XcodeBuildAdapter.measurePerTestCoverage`'s partial-map
  fail-open.
- CI restructured into path-based targeted acceptance groups with a
  fast/system unit split, and per-test coverage runs now skip the
  redundant SwiftPM build-graph check on repeats.

## Upgrade impact

No configuration or CLI-flag changes for existing users. Anyone
pinning the GitHub Action should move to `uses: juntaki/mutantkit@v0.3.0`
(the action's own wiring changed as part of the P13 rebuild).

## Breaking changes

None.
