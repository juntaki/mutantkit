## Highlights

- Root-caused and fixed a real, reproducible CI hang (a plain `swift
  test` run occasionally sitting for 68+ minutes): `ProcessSupervisor`'s
  own pipes were missing close-on-exec, letting a concurrently-spawned,
  long-lived process from an unrelated test hold a fast test's pipe open
  for its whole lifetime under `swift test`'s parallel execution. Fixed
  and covered by a deterministic syscall-level regression test.
- `ToolRunner`'s process spawn/wait/drain path rewritten onto raw
  `posix_spawn`/`waitpid(WNOHANG)` polling against a real deadline,
  mirroring the same technique `ProcessSupervisor` already used, so
  neither path can hang unbounded on a misbehaving subprocess again.
  Every CI job now also carries its own `timeout-minutes`.
- iOS `SimulatorPool` parallel execution (default N=2), plus new
  cross-tool benchmark infrastructure for Muter/swift-mutation-testing
  competitive comparisons.
- Sigstore-backed build-provenance attestation restored in
  `release.yml` (it had been silently dropped in an earlier revision
  while `action.yml` still documented it), with release-job permissions
  scoped to least privilege.
- Two genuine cross-tool benchmark matching bugs fixed: mutant matching
  now uses full canonical identity (path+line+column+operator family),
  never bare position, and an ambiguous match key no longer silently
  drops a second, unrelated candidate.

## Upgrade impact

No configuration or CLI-flag changes. If you run MutantKit's own CI in
a fork, note the added per-job `timeout-minutes` and the CI-side
`--num-workers` cap under GitHub-hosted runners' lower core counts.

## Breaking changes

None.
