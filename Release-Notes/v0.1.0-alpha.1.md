## Highlights

Initial public alpha of MutantKit, a native Swift mutation-testing tool
for Swift and Apple platforms.

- Relational-operator schemata scoring enabled and validated against a
  real-corpus performance benchmark (workers=2, 5 repetitions,
  isolated-vs-schemata disagreement = 0).
- Prebuilt release build script and a clean-machine end-to-end release
  workflow, the basis this project's release process still builds on.

## Upgrade impact

Initial release — no prior version to upgrade from.

## Breaking changes

None (first release).
